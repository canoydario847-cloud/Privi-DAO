# Privi DAO ecosystem inventory

The catalog inventories all eight Privi GitHub repositories discoverable under the connected GitHub account, two known public endpoints, and fourteen named projects/services from Privi planning context, for **24 total entries**.

This is a governance **catalog**, not a claim that the DAO owns, operates, deploys, or controls these services. Private repository URLs are included as identifiers only; they do not expose private code or secrets. Products with unknown deployment state are explicitly `deployment_unverified`.

## Integration stages
1. Catalog inventory (current)
2. Verified owner-controlled endpoint / repo mapping
3. Read-only service telemetry and evidence
4. Draft maintenance proposal linked to service ID
5. Owner-reviewed permission binding / governance approval
6. Controlled execution with independent audit and rollback

On-chain `PriviServiceRegistry` starts empty and must be populated by approved transactions after a verified deployment. Catalog changes do not automatically write to Base or grant Privi AI access.
